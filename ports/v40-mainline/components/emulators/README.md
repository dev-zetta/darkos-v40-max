# V40 common emulators

The full-image build cross-compiles RetroArch 1.22.2 for AArch64 and ARM hard-float and builds the ARMHF PCSX ReARMed core with the Ari64 dynarec and NEON renderer. `source-lock.json` records the upstream revisions and source archive checksums. `emulator-build.json` records output checksums and toolchain package versions. The build uses the verified UTC timestamp as `SOURCE_DATE_EPOCH` for reproducible compiled version messages. The source archive contains the locked inputs and rebuild instructions.

RetroArch continues to use the existing per-architecture configuration and frontend launch arguments. The AArch64 launcher uses the image's private Mesa libraries. The ARMHF launcher uses Debian GLVND dispatch and GBM with the installed Mesa EGL vendor. The manifest records the exact Debian binary and source package versions, and the image includes the notices. Both architecture-specific GO-Super udev profiles receive the tested face-button and stick-axis corrections. Only ARMHF PCSX ReARMed NEON changes cores. [Debian libglvnd source](https://sources.debian.org/src/libglvnd/1.7.0-1/), [Debian Mesa source](https://sources.debian.org/src/mesa/25.0.7-2%2Bdeb13u1/)

Dreamcast, Naomi, and Atomiswave launch the image donor's existing Flycast r7 through the ARMHF Mesa wrapper. The builder verifies that the donor binary matches the tested one. The ArkOS4Clone commit supplies the binary, and the full source revision for its embedded `r7-rc1-3377-gdba78c8ce` version remains unidentified. Copy your own BIOS files to `bios/dc` on EASYROMS, including a complete Naomi BIOS set if you use Naomi. [ArkOS4Clone donor change](https://github.com/lcdyk0517/arkos4clone/commit/9a3e6303e5a42ebf98eb3085cc727652c046c58f)

Run `bash scripts/build_image_emulators.sh NEW_WORK OUTPUT_ROOT` from the V40 port or pass its full path. The build uses the V40 dual-architecture toolchain. For offline rebuilds, set `V40_EMULATOR_SOURCE_DIR` to a directory with both exact locked source archives. During fresh image assembly, `configure-image.py ROOTFS` applies the launcher and profile changes after the overlay is staged onto the pinned donor filesystem.
